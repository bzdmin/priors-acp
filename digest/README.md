# Digest

A minimal ACP provider agent, used as a demonstration counterparty for Priors.

> Digest is a minimal ACP provider created for this project to enable a live,
> reproducible demo transaction. Priors' broader analysis is based on 718
> independent third-party ACP agents; Digest is not part of that dataset.

Figures come from [`docs/DATA.md`](../docs/DATA.md), regenerated by
`scripts/dataset_stats.py`.

## Offering

Registered on the Virtuals Service Registry as `textDigest`:

| | |
|---|---|
| requirement | `{ text: string }` — up to ~2000 words |
| deliverable | `{ summary: string }` — 2-3 sentences |
| price | 0.01 USDC (read from the registry at startup, not hardcoded) |
| SLA | 5 minutes |

The offering name is function-like because the registry requires it; that
string is also what a buyer passes to `createJobByOfferingName`.

## Behaviour

```
job.created            log and wait for the buyer's requirement
message(requirement)   validate, then setBudget() or reject()
job.funded             summarise and submit()
job.completed          log
job.rejected/expired   log; keep listening
```

Rejection happens at the requirement stage, before anything is committed
on-chain, for: an offering name other than `textDigest`, an unparseable
payload, a missing or empty `text` field, or input over 2000 words.

Protocol behaviour is deterministic — the same job always yields the same
accept/reject decision and the same budget. A language model writes only the
summary prose. It never decides whether or how to transact. If
`ANTHROPIC_API_KEY` is absent or the call fails, Digest falls back to
extractive summarisation and still delivers, so a demo does not die on a
missing key.

Digest holds no state between events: the input text is recovered from
`session.entries`, which the SDK hydrates with job history. Restarting
between the requirement and funding is therefore safe.

## Running

```bash
npm install
cp .env.example .env    # then fill in the three SELLER_* values
npm start
```

Digest refuses to start if `textDigest` is not registered for its wallet,
rather than idling and silently failing to serve jobs.
